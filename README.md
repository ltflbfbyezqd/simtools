## 🕹️ Overview

SimTools reads telemetry from racing and flight games and converts it into real-time motion commands sent to DIY motion simulator rigs and commercial platforms.

Whether you're a newcomer or a veteran, SimTools provides the tools you need to get the most out of your gaming tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

---

## ✨ Key Features

| Feature | Description |
|---|---|
| **Telemetry Plugins** | Supports 100+ games including iRacing, Assetto Corsa, and DCS |
| **Axis Tuning** | Configurable min/max travel and smoothing per motion axis |
| **Safety Limits** | Hard limits prevent actuators exceeding safe physical range |
| **Live Preview** | Real-time axis position graph for tuning without running a game |
